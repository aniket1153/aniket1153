Setup Instructions for Snake Animation
Create the GitHub Actions workflow file:

Create a new file at .github/workflows/snake.yml with the following content:

yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 0 * * *"  # Runs daily at midnight UTC
  workflow_dispatch:     # Allows manual trigger

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: Platane/snk@v3
        with:
          github_user_name: your-github-username
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
Enable GitHub Pages:

Go to your repository Settings > Pages

Set Source to Deploy from a branch

Select the output branch and / (root) folder

Click Save

The snake animation will appear in your profile README within 24 hours or can be triggered manually from the Actions tab.

Setup Instructions for GitHub Metrics
Create a GitHub Actions workflow file:

Create a new file at .github/workflows/metrics.yml with the following content:

yaml
name: Metrics
on:
  schedule:
    - cron: "0 0 * * *"  # Runs daily at midnight UTC
  workflow_dispatch:     # Allows manual trigger
jobs:
  github-metrics:
    runs-on: ubuntu-latest
    steps:
      - uses: lowlighter/metrics@latest
        with:
          token: ${{ secrets.METRICS_TOKEN }}
          user: your-github-username
          template: classic
          base: header, activity, community, repositories, metadata
          config_animated: yes
          config_timezone: Asia/Kolkata
          plugin_languages: yes
          plugin_languages_ignored: html, css
          plugin_languages_details: percentage, bytes-size
          plugin_achievements: yes
          plugin_habits: yes
          plugin_habits_charts: yes
          plugin_habits_from: 200
          plugin_habits_days: 14
          plugin_habits_facts: yes
          plugin_calendar: yes
          plugin_calendar_limit: 1
Generate a Personal Access Token:

Go to GitHub Settings > Developer settings > Personal access tokens > Tokens (classic)

Generate a new token with repo and user scopes

Copy the token

Add the token as a secret:

Go to your repository Settings > Secrets and variables > Actions

Click "New repository secret"

Name: METRICS_TOKEN

Value: Paste your token

Click "Add secret"

The metrics will appear in your profile README within 24 hours or can be triggered manually from the Actions tab.

Setup Instructions for WakaTime GitHub Action
Create a GitHub Actions workflow file:

Create a new file at .github/workflows/waka-readme.yml with the following content:

yaml
name: WakaTime Readme

on:
  schedule:
    - cron: "0 0 * * *"  # Runs daily at midnight UTC
  workflow_dispatch:     # Allows manual trigger

jobs:
  update-readme:
    name: Update Readme with WakaTime Stats
    runs-on: ubuntu-latest
    steps:
      - uses: anmol098/waka-readme-stats@master
        with:
          WAKATIME_API_KEY: ${{ secrets.WAKATIME_API_KEY }}
          GH_TOKEN: ${{ secrets.GH_TOKEN }}
          SHOW_LINES_OF_CODE: "True"
          SHOW_PROJECTS: "True"
          SHOW_LANGUAGE: "True"
          SHOW_OS: "True"
          SHOW_EDITORS: "True"
Get your WakaTime API Key:

Sign up at WakaTime

Go to Settings > Account > API Key

Copy your API Key

Add the API key as a secret:

Go to your repository Settings > Secrets and variables > Actions

Click "New repository secret"

Name: WAKATIME_API_KEY

Value: Paste your API Key

Click "Add secret"

Add your GitHub Token as a secret:

Generate a Personal Access Token with repo scope

Add it as GH_TOKEN in the secrets
